#### 4️⃣ Configurar Alertas Prometheus para Pods Não-Ready

**Objetivo**: Detectar problemas semelhantes no futuro

**Criar PrometheusRule**:

```yaml
apiVersion: monitoring.coreos.com/v1
kind: PrometheusRule
metadata:
  name: app-alerts
  namespace: default
spec:
  groups:
  - name: app-availability
    interval: 30s
    rules:
    - alert: PodNotReady
      expr: kube_pod_container_status_ready{namespace="default", pod=~"app-.*"} == 0
      for: 5m
      labels:
        severity: critical
      annotations:
        summary: "Pod {{ $labels.pod }} não está ready"
        description: "Container {{ $labels.container }} no pod {{ $labels.pod }} não está ready há mais de 5 minutos."

    - alert: PodImagePullError
      expr: kube_pod_container_status_waiting_reason{namespace="default", pod=~"app-.*", reason=~".*Image.*"} == 1
      for: 2m
      labels:
        severity: critical
      annotations:
        summary: "Erro de pull de imagem no pod {{ $labels.pod }}"
        description: "Container {{ $labels.container }} falhou ao fazer pull da imagem. Motivo: {{ $labels.reason }}"

    - alert: DeploymentReplicasUnavailable
      expr: kube_deployment_status_replicas_available{namespace="default", deployment="app"} == 0
      for: 5m
      labels:
        severity: critical
      annotations:
        summary: "Deployment app sem réplicas disponíveis"
        description: "Deployment app não tem nenhuma réplica disponível há mais de 5 minutos."
```

O deployment deve referenciar uma imagem válida:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: app
  namespace: default
spec:
  replicas: 1
  selector:
    matchLabels:
      app: app
  template:
    metadata:
      labels:
        app: app
    spec:
      containers:
      - name: app
        image: <registry>/<namespace>/<image>:<tag>  # Esta linha deve estar correta
        ports:
        - containerPort: 5000
        env:
        - name: DB_HOST
          value: postgres-service
        - name: DB_USER
          value: ecommerce
        - name: DB_PASSWORD
          valueFrom:
            secretKeyRef:
              name: postgres-secret
              key: password
```
